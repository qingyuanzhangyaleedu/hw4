# Campus Customs frontend

React + TypeScript app scaffolded with Vite's `react-ts` template. See [the project README](../README.md) for installation, backend startup, tests, and the full checklist.

```bash
npm ci
npm run dev -- --port 5173
```

The backend must also be running on port 8000. Vite proxies `/api` and `/images` to it.

```bash
npm run build
npm run lint
```
